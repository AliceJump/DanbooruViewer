# 标签屏蔽与本地数据

## 添加和管理

从图库右上角的 **设置 → 标签屏蔽** 进入管理页。可一次粘贴多个原始 Danbooru 标签，用空格或换行分开；列表可搜索、删除和撤销删除。详情中的标签菜单也提供 **屏蔽此标签** 和撤销操作。详情添加会同时启用屏蔽、结束临时显示。

规则保存完整标签，忽略首尾空白和大小写，重复标签只保留一次。任一标签命中就隐藏作品。例如屏蔽 `cat` 会隐藏带有完整 `cat` 标签的作品，不会隐藏只有 `cat_ears` 的作品。请使用原始英文标签，而不是中文翻译显示名。

第一版最多保存 2000 个标签，每个标签最多 512 字符。不解释 AND、负标签、通配符或其他搜索语法：输入的每个词都是独立的完整标签。

## 显示范围与恢复

同一份规则用于首页和搜索结果、收藏、历史、收藏标签预览、详情及全屏翻页。旧收藏缺少总标签字段时，也会检查已有的分类标签字段。

屏蔽保留原始作品、收藏和历史。**临时显示** 可以在当前进程中查看被屏蔽作品，**恢复屏蔽** 立即重新过滤；关闭应用后不会保留临时显示状态。**启用标签屏蔽** 开关则会持久保存。

规则变化会立即重新过滤已经加载的内容，不需要重新请求。隐藏的作品会退出多选；详情正在播放的作品被隐藏时会停止播放，并切换到原始顺序中的下一个可见作品，或显示明确的空状态。全屏和详情以作品 ID 同步位置，避免过滤后索引错位。

批量保存会在每项开始或重试前重新检查可见性。已隐藏的排队项显示 **已跳过**，不会计入保存成功；关闭队列后只保留仍可见的未完成选择。已经开始的保存不会因规则变化自动撤销。

## 连续空页与翻页

本地过滤不改变发给 Danbooru 的查询，也不把被屏蔽的服务器页面当作最后一页。一次请求操作最多连续读取三页：只要找到新增可见作品就停止；三页都被屏蔽时显示 **继续加载**。只有服务器返回空列表才结束分页。

这个上限控制请求量；遇到连续大量被屏蔽的作品，需要手动继续加载。若补页中途失败，重试仍从失败的页面开始，先前成功加载的内容继续保留。

## 损坏或保存失败

应用不会把无法解析的收藏、历史或屏蔽数据当作空列表写回。读取失败时会提示重试，并允许复制原始内容。设置中的 **复制收藏备份** 包含收藏、收藏标签、历史和屏蔽设置；即使字段类型或 JSON 已损坏，也保留原始值，便于人工恢复。

如果旧版只保存了收藏作品编号，没有完整的收藏记录，应用仍能识别这些编号的收藏状态。收藏列表会显示恢复提示，并阻止添加、移除或切换收藏，保留原编号供备份。当前不会编造缺失的作品详情，也不会自动抓取详情或导入备份；仅有编号的数据需要先恢复完整记录才能继续修改。

复制后可粘贴到文本文件保存。备份不包含网络代理设置、账号或请求日志；当前没有自动导入或跨设备同步功能。

收藏、屏蔽规则和网络设置共用串行写入保护。Android 可能先更新原生内存，再报告磁盘写入失败；普通重新读取仍会返回该内存值，不能证明保存成功或旧值已经恢复。因此，应用保留上次确认保存的内容，失败时显式写回旧值，只有平台确认写回成功后才解除保护。

恢复尚未确认时，界面和备份使用上次确认的数据，新的偏好修改必须先成功恢复，防止另一项设置的保存把失败值一起写入磁盘。备份中的 `recovery_keys` 会标明待恢复的字段；备份值不冒充磁盘的实时读取结果。读取和备份也会等待正在进行的写入结束。

收藏页的重试或刷新、屏蔽管理页的重试读取会先尝试恢复，再重新读取。故障仍在时继续保留原值并提示错误；故障解除后可重试原操作。完整收藏记录已经成功保存时，旧编号副本的失败不会把已完成的收藏切换报告为失败，避免用户重试反而取消收藏。
